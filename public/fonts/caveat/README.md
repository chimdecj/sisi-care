# Caveat

Caveat is used for the site's standalone handwritten notes. The variable Latin font supports weights 400–700 and is self-hosted through `next/font/local`; visitors do not request fonts from Google.

- Source: https://github.com/google/fonts/tree/main/ofl/caveat
- Web font: https://fonts.gstatic.com/s/caveat/v23/Wnz6HAc5bAfYB2Q7ZjYY.woff2
